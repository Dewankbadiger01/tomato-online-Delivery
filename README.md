Tomato – Food Delivery Partner Platform
Tomato is an online food-delivery platform prototype built to demonstrate the main workflows of a food delivery service, including restaurant/partner operations and customer-facing ordering experiences.

Live demo: [https://tomato-food-delivery-partner-platform.ai.studio](https://tomato-food-delivery-partner-platform.ai.studio)
Project Overview
The goal of Tomato is to provide a simple, user-friendly platform for browsing food, managing orders, and supporting restaurant partners. The project is being developed as a web application prototype.

User Acceptance Testing (UAT)
Suggested checks for a project demonstration:
1. Open the live demo and confirm the home page loads.
2. Navigate through the available pages and sections.
3. Test food/menu browsing and search, if implemented.
4. Test the cart and quantity controls, if implemented.
5. Test the checkout/order flow, if implemented.
6. Test restaurant/partner dashboard actions, if implemented.
7. Check the layout at desktop and mobile widths.
8. Record each test as Pass or Fail and capture screenshots of the actual results.
